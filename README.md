# Catenator

Catenator turns intent into something real, and makes sure what comes out can be trusted.

You describe what you're making and who it's for. Catenator shapes that into the right output for the right person — the same intent, refracted differently depending on who's receiving it. Not one generic version everyone has to make sense of alone.

This isn't one document. It's five, because the same underlying idea looks different depending on who you are and what you're trying to do with it. Pick the one that's actually you.

## Which one is you?

- **Designing something — visual, written, or otherwise?** Start with [Creators](creators/README.md).
- **Writing user guides, references, or documentation for a product?** Start with [Tech writers](tech-writers/README.md).
- **Building an AI system to answer questions from a knowledge base, from scratch?** Start with [Knowledge teams](knowledge-teams/README.md).
- **Adding AI answering on top of a product that already has real users, roles, and permissions?** Start with [Integrators](integrators/README.md).
- **Want the actual technical standard — the schema, the coordinate model, how governance and delivery work underneath all of this?** Start with [Governing docs](governing-README.md).

If none of these sound like you, this probably isn't for you yet — and that's fine.
